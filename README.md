# ASSAYER — Industrial Solutions

Static company website. Seven pages, no build step: every image is embedded
in the HTML and the only external request is Google Fonts.

Served by GitHub Pages from `main`. `.nojekyll` is present so Pages publishes
the files as they are.

| file | page |
|---|---|
| `index.html` | home |
| `chemicals.html` | مواد كيميائيّة |
| `equipment.html` | معدّات وأجهزة |
| `software.html` | برمجيّات المختبرات |
| `trade.html` | وساطة تجاريّة |
| `method.html` | الطريقة |
| `standards.html` | كيف تُقرأ مواصفة |
